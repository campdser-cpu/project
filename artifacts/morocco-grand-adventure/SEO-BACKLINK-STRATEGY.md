# SEO Backlink Strategy — Morocco Grand Adventure

**Principle:** earn editorial links because the content is genuinely useful. No purchased links, no PBNs, no mass directories, no automated link spam, no fake reciprocal schemes, and **no automatic outreach to competitor sites** (sahatours.net, viajeenmarruecos.com are research references only — they are NOT outreach targets).

## 1. Linkable assets to build (original, first-hand)

| Asset | Format | Why it earns links | Status |
|---|---|---|---|
| Ultimate Merzouga Travel Guide | Long-form guide cluster (seoHub) | Most complete first-hand Merzouga resource in EN; citable reference | Hub exists; deepen per gap report |
| Marrakech → Merzouga Route Guide | Route resource with map/stops | Route queries are highly cited in trip-planning threads | Planned (gap report) |
| Fes → Merzouga Route Guide | Route resource | Same as above, thinner competition | Planned |
| Morocco Desert Packing List | Checklist | Widely referenced, seasonal reposts | Blog exists; improve |

| Morocco Itinerary Planner | Structured itineraries (existing tours) | Reference for planners and bloggers | Partial (tour pages) |
| Sahara Desert Travel FAQ | FAQ hub | Eligible FAQPage schema where genuinely on-page | Partial (hub FAQs) |

Rules: each asset must contain facts we can verify first-hand. Official photos (approved MGA set only) give editorial writers a reason to cite **and credit** the site.

## 2. Outreach categories (legitimate relationship-based)

1. **Travel media & magazines** — adventure/luxury travel publications covering North Africa. Pitch first-hand story angles (private Land Cruiser Sahara crossings, Berber-guided Erg Chebbi) — not "please link to us".
2. **Independent Morocco travel bloggers & guides** — bloggers who already write Morocco itineraries and may reference a useful route/packing resource.
3. **Travel photographers & creators** — YouTubers/TikTok/Instagram creators shooting Sahara content; the official first-party library is a collaboration asset (usage/credit agreements).
4. **Local tourism ecosystem** — regional tourism bodies (Errachidia/Midelt/Merzouga region), local associations, riads, desert camps, restaurants, activity providers we genuinely work with. Natural supplier/partner listing exchanges only where real relationships exist.
5. **Journals & universities with Morocco/African-studies programs** — for factual cultural/geography resources only if we create something rigorously useful.

## 3. What we will NOT do
- Buy links or placements.
- Participate in link exchanges with competitors.
- Mass-submit to low-quality directories.
- Generate doorway "resources" purely to host outbound links.
- Fabricate credentials, awards, or press mentions.

## 4. Measurement [GSC-VALIDATE]
- Track referring domains monthly (Search Console links report).
- Correlate link acquisition with impressions/CTR changes on target pages.
- Do not judge a link by one day of data; evaluate over 4–8 weeks per the GSC feedback loop.
