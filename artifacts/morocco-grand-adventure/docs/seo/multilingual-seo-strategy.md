# Morocco Grand Adventure — Multilingual SEO/GEO Strategy

Research-based (not translation-based) strategy per locale. Competitor sources are
reference material only — all MGA copy remains original. Version 1, 2026-09-10.

## 1. Method

For each locale: (a) studied 1–3 SERP-visible Morocco operators + the official ONMT
site in that language + encyclopedic naming sources; (b) extracted **terminology,
taxonomy and search-intent signals**; (c) mapped signals onto MGA's existing route
architecture (never creating thin doorway pages); (d) authored locale-native
metadata (see §8) rather than translating the English strategy.

## 4. Keyword → URL map (anti-cannibalization, applies in every locale)

| Primary intent | Target URL | Rule |
|---|---|---|
| "{morocco} tours" (pillar) | `/` (home) | one pillar per language; never duplicated on /tours |
| tour catalog / list | `/tours` | descriptive catalog intent, not the pillar |
| "{morocco} desert tours" | `/desert-tours` | own intent, own page |
| tours from {city} | `/marrakech-tours`, `/fes-tours`, `/casablanca-tours`, `/agadir-tours`, `/tours/from-*` | city+departure intent |
| {city} to Merzouga {N} days | `/tours/<id>` | route intent — one page per real tour |
| "{morocco} itinerary {N} days" | `/tours/from-<city>/<n>-days` | duration hubs (already architected) |
| luxury desert camp | `/luxury-camp` | accommodation intent |
| camel trekking | `/camel-trekking` | activity intent |
| 4x4 desert excursion | `/4x4-tours` | activity intent |
| day trips | `/day-trips`, `/build-your-day-trip` | same-day intent |
| destination research | `/destinations`, `/destinations/:id` | informational |
| custom/private planning | `/trip-builder` | conversion intent |
| Merzouga know-how | `/merzouga-guide`, `/merzouga-guide/:slug` | informational cluster |

No new URLs were created in this phase → **zero cannibalization risk**. Any future
new page must first claim an unassigned intent row in this table.

## 5. Content gaps (existing pages to strengthen later, priority order)

1. `/desert-tours` hub intros in non-EN locales still render English body copy (metadata now localised) — author hub bodies next.
2. Duration hubs for high-demand lengths (7/10 d from Marrakech) — deepen intro copy with locale entities.
3. Merzouga activities cluster (`/4x4-tours`, `/camel-trekking`, `/luxury-camp`) — cross-link from tour detail pages.
4. Blog: add per-locale titles (overlay pattern already supports it).

## 6. Internal linking opportunities

- City hubs ↔ duration hubs ↔ tour detail (exists); add "activities" cross-links from the desert-tours hub.
- Destination detail → nearest route tour (e.g. erg-chebbi → 3-day tours) via existing related-tours slots.

## 7. GEO / AI-answer readiness

Every commercial page already carries WHAT/WHO/WHERE/HOW LONG/INCLUDED/WHEN/HOW-TO-BOOK
structure + FAQ + schema. Keep: explicit start city, duration and booking method in
the first screen of each locale's content; do not invent prices.

dictionaries (FR/ES/DE/IT/NL/PT/ZH/JA/KO — joining the existing AR + IT-partial ones)
