# Video SEO Package — moroccograndadventure.com

This folder contains 5 short-form travel reels (originally from Instagram) renamed
with SEO-friendly filenames, plus full metadata for each so they can be embedded
in the website with proper on-page SEO, alt text, and schema markup.

**Instructions for Cline:** Use the metadata below (also available in
`video-metadata.json` for programmatic use) to:
1. Place each video on the most relevant page/section of the site (see "Suggested
   page" per video).
2. Add the title, meta description, and alt text exactly as written (or adapt
   lightly to match existing page tone).
3. Generate `VideoObject` JSON-LD schema for each video using the template at
   the bottom of this file — this is what allows the videos to show up in
   Google video search results.
4. Compress/transcode videos for web (see "Technical notes" at the bottom)
   before publishing — the originals are Instagram exports and are heavier
   than needed for web delivery.

## Technical notes for Cline

- Source files are vertical (9:16) Instagram exports — good for a mobile
  hero/reels section, but re-encode with `ffmpeg -vcodec libx264 -crf 23
  -preset slow -movflags +faststart` and strip audio if unused, to cut load
  time.
- Add a `poster`/thumbnail image (first frame or a hand-picked frame) for each
  `<video>` tag so pages don't show a blank box while loading.
- Wrap each video in `<video>` with `preload="metadata"` and lazy-load below
  the fold to protect Core Web Vitals (LCP/CLS).
- Use the JSON-LD `VideoObject` template below per video (fill in
  `contentUrl`, `thumbnailUrl`, `uploadDate`, and `duration` once hosted).

```json
{
  "@context": "https://schema.org",
  "@type": "VideoObject",
  "name": "REPLACE: title tag from above",
  "description": "REPLACE: meta description from above",
  "thumbnailUrl": "REPLACE: URL to poster image",
  "contentUrl": "REPLACE: URL to hosted mp4",
  "uploadDate": "REPLACE: ISO 8601 date",
  "duration": "REPLACE: e.g. PT00M13S"
}
```
